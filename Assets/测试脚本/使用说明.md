# 单轮机器人第三人称控制器

## 操作与动画

- W：沿机器人自身朝向前进，平滑混合到 FBX 中的 Drive Fast。
- S：保持面朝方向倒退，使用 Idle_01 基础动作，叠加后倾和轮子反向滚动。
- A / D：向左 / 向右改变朝向，模型向转弯方向侧倾。支持原地转向和边移动边转向，不横向平移。
- 松开按键：平滑减速、回正；停止后循环 Idle_01。
- 带重力、地面碰撞和 CharacterController 台阶处理，没有跳跃。

## 手动布置角色

1. 新建空物体 RobotRoot，作为移动和碰撞的根节点。保持直立、缩放为 1，位置放在轮子接地点。
2. 在 RobotRoot 下新建空物体 VisualPivot，局部位置和旋转归零、缩放为 1。
3. 将 Cute_Robot_05 模型或同名预制体放到 VisualPivot 下。调整模型本身的局部位置、旋转和缩放，使轮底对齐 RobotRoot 原点，机器人面向 RobotRoot 的蓝色 Z 轴正方向。VisualPivot 保持归零，倾斜会围绕轮底发生。
4. 给 RobotRoot 添加 SingleWheelRobotController，CharacterController 会自动添加。不要再添加 Rigidbody 或其他移动控制脚本。
5. 将 VisualPivot 拖入 Visual Pivot，将机器人模型自身的 Animator 拖入 Robot Animator。
6. 脚本首次添加时会尝试从指定 FBX 自动填写两段动画。若引用没有填好，在组件右上角菜单选择“自动绑定机器人引用和动画”，或展开 FBX，手动拖入名称结尾为“_ Idle_01”和“_ Drive Fast”的两个动画片段。
7. 无需创建 Animator Controller、参数或过渡；保持模型 Animator 组件启用。运行时脚本接管动画，禁用脚本时恢复原有 Controller 和 Animator 设置。不要同时使用其他脚本或 Timeline 驱动这个 Animator。
8. 按机器人实际尺寸调整 CharacterController 的 Height、Radius、Center，使胶囊底部对齐轮底、整体包住机器人。默认高度 2、半径 0.35、Center Y 为 1，只是起始值。地面需要有 Collider。

动画与轮子骨骼应在同一个模型的 Animator 层级内。倾斜只施加给 VisualPivot，碰撞胶囊保持直立。不要把 Visual Pivot 指向模型自身、骨骼或 RobotRoot。

## 第三人称相机（可选）

将 RobotThirdPersonCamera 挂到独立的 Main Camera 上，Target 拖入 RobotRoot。相机会平滑跟随到机器人身后，不跟随模型侧倾。Follow Offset 默认是后方 4.5、上方 2.2，可按模型大小调整；Look At Height 控制注视高度。相机物体不要放在机器人层级内，也不要同时启用其他相机跟随组件或 Cinemachine 驱动这台相机。这个简单相机不处理墙体遮挡。

Framing Offset 单独控制机器人在画面中的构图位置，不改变相机原有朝向，单位为米。X 为正时相机向画面右方平移，机器人出现在画面偏左；X 为负时机器人偏右。Y 为正时机器人偏下，Y 为负时机器人偏上。默认 X 为 1、Y 为 0；设置成 0、0 可以恢复居中构图。Follow Offset 与 Look At Height 继续控制拍摄角度和距离。

## 常用调节

- Forward Speed / Reverse Speed：前进 / 倒退速度，默认 4 / 2。
- Acceleration / Braking：加速 / 减速强度。
- Turn Speed / Turn Acceleration：转向速度 / 转向响应。
- Turn Lean Angle：转弯最大侧倾，默认 16 度；Stationary Turn Lean 控制原地转向的侧倾比例。
- Reverse Lean Angle：倒退最大后倾，默认 12 度；实际倒退速度越大，后倾越明显。
- Lean Response：倾斜与回正速度，越大越迅速。
- Animation Blend Speed：Idle 与 Drive Fast 的混合速度。
- Animate Reverse Wheel：控制是否叠加倒退滚轮；脚本会自动寻找名为 Wheel 的骨骼，也可以手动指定 Wheel Bone。
- Wheel Radius：轮子世界空间半径，默认 0.23。缩放模型后相应调整；如果倒退轮子方向反了，将 Wheel Local Axis 的 X 从 1 改为 -1。

脚本直接读取 WSAD，兼容项目当前启用的 Input System，不需要 Input Actions、PlayerInput 或旧版轴设置。先点击 Game 窗口，让键盘输入获得焦点。

交付时只做静态编译检查；没有打开 Unity、修改场景或执行场景测试。实际胶囊尺寸、模型朝向和倾斜效果请在你布置完成后确认。
